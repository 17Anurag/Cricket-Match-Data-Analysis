# 🏏 Cricket Match Data Analysis

## 📌 Project Overview

The Cricket Match Data Analysis project focuses on extracting meaningful insights from historical cricket match data using data analytics and visualization techniques. The objective is to analyze team performances, player statistics, match outcomes, and various factors influencing the results of cricket matches.

By leveraging Python for data cleaning and exploratory data analysis (EDA) and Tableau for interactive dashboard creation, this project transforms raw cricket datasets into actionable insights that can help understand trends and patterns within the game.

---

## 🎯 Objectives

* Analyze overall team performance across matches.
* Identify top-performing batsmen and bowlers.
* Study the impact of toss decisions on match outcomes.
* Evaluate venue-wise team performance.
* Discover scoring trends and wicket-taking patterns.
* Build interactive dashboards for data-driven decision-making.

---

---

## 📂 Dataset Information

The dataset contains cricket match records, including:

* Match Details
* Team Names
* Toss Winner
* Match Winner
* Venue Information
* Player Statistics
* Runs Scored
* Wickets Taken
* Match Results

---

## 🔍 Exploratory Data Analysis (EDA)

The following analyses were performed:

### Team Analysis

* Total matches played by each team
* Team win percentages
* Home vs away performance

### Batting Analysis

* Top run scorers
* Average runs scored
* Boundary statistics

### Bowling Analysis

* Highest wicket takers
* Economy rate analysis
* Bowling performance trends

### Match Analysis

* Toss impact on winning probability
* Venue-wise winning patterns
* Match result distributions
